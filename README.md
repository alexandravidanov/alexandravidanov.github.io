# Alexandra Vidanov – Portfolio

Persönliche Portfolio-Website, veröffentlicht über GitHub Pages.

Live: https://alexandravidanov.github.io

## Aufbau
- `index.html` – Inhalt der Seite (alle Texte)
- `style.css` – Gestaltung (Schrift Lato, Akzentfarbe #F79315)
- `assets/` – Fotos und das DARK-MATTER-Video

## Änderungen veröffentlichen
Datei ändern → speichern → in VS Code unter „Source Control“ eine kurze Nachricht schreiben → **Commit** → **Sync/Push**.
Nach 1–3 Minuten ist die Änderung online.

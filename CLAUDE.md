# Projektnotizen für Claude Code

Statische Portfolio-Website von Alexandra Vidanov (Kulturwissenschaften/Medienwissenschaften, Leuphana; Museumsführungen MK&G Hamburg; Social Media Content). Veröffentlicht mit GitHub Pages aus dem Branch `main`, Ordner `/` (root). Kein Build-Schritt, kein Framework: reines HTML + CSS.

## Dateien
- `index.html`: alle Inhalte, Sprache Deutsch.
- `style.css`: Gestaltung. Mobile Regeln stehen in der Media Query am Ende.
- `assets/`: Bilder (JPG) und `dark-matter.mp4`. Neue Bilder vor dem Hochladen auf max. ca. 1800 px Breite und unter 500 KB verkleinern.
- `.nojekyll`: verhindert, dass GitHub Jekyll ausführt. Nicht löschen.

## Gestaltung (beibehalten)
- Schrift: Lato (Google Fonts), für alles.
- Eine Akzentfarbe: Orange `#F79315`. Sonst Schwarz/Weiß/Grau.
- Projekt-Abschnitte: Foto als Hintergrund, Text in weißem Kasten davor, Bildnachweis unten.
- Keine Emojis, keine Monospace-Schrift, keine nummerierten Labels, keine Slogan-Überschriften, keine Buzzwords.

## Texte
- Die Texte stammen von Alexandra. Wortlaut nicht ohne Auftrag umschreiben; nur ändern, was sie verlangt. Rechtschreibfehler darf man melden und nach Rückfrage korrigieren.
- Ich-Form, kurze Sätze, keine Übertreibungen, keine erfundenen Zahlen oder Fakten.

## Arbeitsweise
- Nach Änderungen die Seite lokal prüfen (index.html im Browser öffnen, auch schmale Fensterbreite für Handy).
- Commit-Nachrichten kurz und auf Deutsch, z. B. „Text Bachelorarbeit aktualisiert“.
- Nach dem Push ist die Seite in 1–3 Minuten unter https://alexandravidanov.github.io aktualisiert.
